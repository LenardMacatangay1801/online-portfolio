# Lenard Macatangay — Resume Website

Cyberpunk-inspired dark portfolio for Frontend / Full-Stack / Website Developer roles.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion

## Run locally

```bash
cd resume-website
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Edit content

Update `src/data/resume.ts` for name, skills, projects, education, and contact links.
Replace `public/profile.png` for a new photo.
Drop a PDF into `public/` and wire the download buttons when ready.
